ЛУРЕН | УЧЕБНАЯ ИНФОРМАЦИОННАЯ СИСТЕМА

Три формы Windows Forms:
1. FrmLogin.cs - авторизация.
2. FrmProducts.cs - каталог, база товаров, поиск, фотографии.
3. FrmClient.cs - информация о клиентах, поиск, редактирование.

КАК ЗАПУСТИТЬ
1. Полностью распакуйте ZIP-архив в отдельную папку.
2. Откройте LurenStore.sln через Visual Studio 2022 с поддержкой .NET Framework 4.8.
3. Вверху укажите конфигурацию Debug и платформу x64.
4. Правой кнопкой по решению -> Восстановить пакеты NuGet.
5. Сборка -> Пересобрать решение, потом F5.

УЧЕБНАЯ УЧЕТНАЯ ЗАПИСЬ
Логин: admin
Пароль: 1234

ПЕРЕХОДЫ
Логин -> ВОЙТИ -> форма товаров -> КЛИЕНТЫ -> форма клиентов -> НАЗАД.
Выход из формы товаров возвращает на экран входа.

ЧТО ГДЕ НАХОДИТСЯ
FrmLogin.cs, FrmProducts.cs, FrmClient.cs содержат обработчики кнопок.
Одноименные Designer.cs содержат элементы интерфейса, которые можно менять через Конструктор Visual Studio.
AssetImages.cs загружает картинки из папки Assets при запуске.
Database.cs работает с настоящей локальной базой SQLite.

ВАЖНО ПРО БАЗУ
Данные автоматически сохраняются в файле:
%LOCALAPPDATA%\LurenStore\luren.db
Этот файл сохраняется между запусками.
При самом первом запуске из папки Data копируется тестовая база с 5 товарами и 3 клиентами.
Если вы обновили проект, старые изменения в AppData не удаляются автоматически.
Чтобы сбросить демонстрационные данные, закройте программу, сохраните копию базы и удалите файл luren.db из указанной папки.

ПРО ФОТО
7 встроенных фотографий находятся в Assets и доступны без интернета.
На форме товаров изображение меняется по категории выбранного товара.

О ФАЙЛАХ
Все элементы находятся в Windows Forms Designer и доступны через Панель элементов.
В C# нет комментариев //, как требуется для сдачи.
Проект использует NuGet пакеты System.Data.SQLite и SourceGear.sqlite3; для сборки нужна платформа x64.
